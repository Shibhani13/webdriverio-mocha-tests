# WebdriverIO + Mocha Automation Framework

This repo contains E2E test automation using [WebdriverIO](https://webdriver.io/) and Mocha.

## 🔧 Tech Stack
- WebdriverIO
- Mocha
- Node.js
- Chromedriver

## 🏁 Run Locally

```bash
git clone https://github.com/yourusername/webdriverio-mocha-tests.git
cd webdriverio-mocha-tests
npm install
npx wdio run wdio.conf.js
npm test
npx wdio run wdio.conf.js --mochaOpts.grep="@login_flow"
```
